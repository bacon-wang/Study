# 07: 统计与库存状态

**What to build:** 管理员能看到每本书被借过多少次、最热门的前 K 本，以及每本在馆图书现在在谁手里。

**Blocked by:** 05（借阅图书）

**Status:** ready-for-human

- [ ] 借阅次数统计：列出每本图书的累计借阅次数（等于它的借阅记录条数），已下架的也列出并标注"已下架"
- [ ] 归还不会减少累计借阅次数
- [ ] 热门前 K：只算在馆图书，按累计借阅次数降序，次数相同按 ID 升序
- [ ] K 大于在馆图书数时返回全部在馆图书
- [ ] K 不是正整数时提示，并重新输入
- [ ] 库存状态：列出每本在馆图书是否在借，在借的显示借给了哪位读者
