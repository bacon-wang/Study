# 01: 登录与注销

**What to build:** 用户启动程序，输入自己的用户 ID 登录，看到所属角色（管理员或读者）的菜单；可以注销回到登录界面，也可以在登录界面退出程序。这一张打通从界面层到文件的全部四层，后面的票据都在它上面加功能。

**Blocked by:** None (can start immediately)

**Status:** ready-for-human

- [ ] 启动时读入用户文件；文件缺失、没有数据行或表头不符时，提示原因后退出
- [ ] 输入存在的用户 ID 登录成功，显示欢迎信息和该角色的菜单
- [ ] 输入不存在的 ID 或非数字时提示，并重新输入
- [ ] 管理员和读者只看到各自可用的菜单项（还没实现的功能可以先不列出）
- [ ] 菜单里输入不存在的编号或非数字时提示，并重新输入
- [ ] 选择注销回到登录界面，另一位用户可以接着登录
- [ ] 在登录界面选择退出时，程序正常结束
- [ ] 为登录服务写第一批服务测试（临时目录 + 真实文件），作为后续测试的样板
