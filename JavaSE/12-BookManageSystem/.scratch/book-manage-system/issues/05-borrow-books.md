# 05: 借阅图书

**What to build:** 读者按图书 ID 借走一本可借的图书；之后浏览馆藏时能看到这本书在借。所有和"在借"相关的限制都在这一张实现，包括不能下架在借的图书。

**Blocked by:** 04（修改与下架图书）

**Status:** ready-for-human

- [ ] 读者按 ID 借阅可借的图书，生成一条借阅记录，借出日期取注入的 Clock
- [ ] 借阅成功后，浏览馆藏时这本书显示为在借
- [ ] 借一本在借的图书时被拒绝，并提示原因
- [ ] 借一本不存在或已下架的图书时，提示"图书不存在或已下架"
- [ ] 读者已有 5 本在借时再借被拒绝，提示借阅上限；上限取自配置
- [ ] 管理员下架一本在借的图书时被拒绝，并提示原因
- [ ] 借阅记录文件不存在时视为空，正常启动；重启后借阅关系仍然在
- [ ] 保存失败时提示"保存失败"，这次借阅不生效
