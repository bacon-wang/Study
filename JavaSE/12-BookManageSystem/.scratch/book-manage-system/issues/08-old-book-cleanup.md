# 08: 旧书清理

**What to build:** 管理员列出长期没人借的旧书，确认一次就把它们全部下架。

**Blocked by:** 05（借阅图书）

**Status:** ready-for-human

- [ ] 列出旧书：上架满旧书阈值，并且最近阈值天数内没有借阅记录的可借图书；"今天"取注入的 Clock
- [ ] 上架满阈值、从没借过的可借图书也在清单里
- [ ] 在借的图书和阈值天数内被借过的图书不在清单里
- [ ] 确认后，清单里的图书全部下架；不确认则什么都不改变
- [ ] 没有旧书时直接提示，不要求确认
- [ ] 旧书阈值默认 365 天，可在配置里调整
