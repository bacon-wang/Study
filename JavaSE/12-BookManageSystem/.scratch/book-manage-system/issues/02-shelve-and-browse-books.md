# 02: 上架与浏览馆藏

**What to build:** 管理员录入一本新书上架，任何用户浏览馆藏都能看到它；关掉程序重新打开，书还在。

**Blocked by:** 01（登录与注销）

**Status:** ready-for-human

- [ ] 管理员录入书名、作者、类别、出版年份上架；系统分配 ID（已有最大 ID + 1），上架日期取注入的 Clock
- [ ] 书名、作者、类别去掉首尾空格后为空时，提示并重新输入
- [ ] 出版年份不是整数，或不在 1 到今年之间时，提示并重新输入
- [ ] 管理员和读者都能浏览全部在馆图书，并看到是否在借（这时还没有借阅，全部显示可借）
- [ ] 重启后上架的书仍然在
- [ ] 书名含 Tab、换行、反斜杠、逗号时，重启后原样显示
- [ ] 图书文件不存在时视为空馆藏，正常启动；第一次上架时创建文件
- [ ] 保存失败时提示"保存失败"，这次上架不生效，浏览时看不到这本书
