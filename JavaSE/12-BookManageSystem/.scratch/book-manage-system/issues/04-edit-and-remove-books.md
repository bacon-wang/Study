# 04: 修改与下架图书

**What to build:** 管理员可以更正一本在馆图书的信息，也可以把它下架；下架后这本书从所有面向借阅的视图里消失，但它的 ID 永远不会再分配给别的书。

**Blocked by:** 03（查找图书）

**Status:** ready-for-human

- [ ] 管理员按 ID 修改在馆图书的书名、作者、类别、出版年份；直接回车的字段保留原值
- [ ] 修改时的字段校验和上架时相同
- [ ] 管理员按 ID 下架在馆图书，状态变为已下架，不能恢复
- [ ] 已下架的图书不再出现在浏览和模糊查找结果里
- [ ] 按 ID 查找、修改、下架一本已下架或不存在的图书时，提示"图书不存在或已下架"
- [ ] 下架后再上架新书，新 ID 不会复用已下架图书的 ID，重启后也一样
- [ ] 修改和下架在重启后仍然有效
